# DataFest Patient Journey / RaceDiff

This project is a DataFest healthcare analytics project focused on understanding patient movement from admission to discharge. It uses healthcare-style data to study how demographic, geographic, behavioral, clinical, and provider-related factors shape the patient journey.

This project won **Best Data Visualization**, recognizing the way the analysis communicated complex healthcare patterns through clear visual storytelling.

## Project Focus

The main goal of this project is to understand how different factors influence patient outcomes and movement through the healthcare system.

The analysis explores:

- Patient demographics
- Geographic patterns
- Behavioral and social context
- Clinical information
- Provider-related patterns
- Admission-to-discharge movement
